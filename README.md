# Zavoryn — Final Static Portfolio

Plain HTML/CSS/JS. No framework, build step, database or admin panel.

## Automatic visual catalogue
Upload images to the matching GitHub folders, commit to `main`, and refresh the site.

- assets/img/post-designing/
- assets/img/brand-designing/logos/
- assets/img/brand-designing/letterheads/
- assets/img/brand-designing/business-cards/
- assets/img/brand-designing/stationery/
- assets/img/brand-designing/brand-guidelines/
- assets/img/social-media-management/
- assets/img/ai-automation/

The public GitHub Contents API lists the images automatically. No token is required for a public repository.

## Website projects
Edit `assets/portfolio-data.js` to add website cards with title, description, cover and URL.

## Contact
The form opens `mailto:zavoryn@outlook.com`; submissions are not stored by the static site.
